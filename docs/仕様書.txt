自分年表 仕様書


============================================================
概要
============================================================

アプリ名:   自分年表
ジャンル:   パーソナルタイムライン + ポートフォリオ

どんなアプリ?
  生まれた年から現在までの出来事を年表として記録するアプリ。
  学業、仕事、スキル、作品、資格、プライベートなどカテゴリ別に管理。
  「作品」や「スキル」カテゴリにはリンクや画像URLを添付可能。
  記録した年表をそのまま美しいポートフォリオとしてHTMLファイルに書き出せる。

誰が使う?
  自分の人生を振り返りたい人、就活・転職でポートフォリオが必要な人。


============================================================
機能一覧
============================================================

イベント登録/編集/削除
  タイトル
  年月 (年 + 月)
  カテゴリ (学業 / 仕事 / スキル / 作品 / 資格 / プライベート / その他)
  説明 (自由記述)
  リンクURL (任意、作品カテゴリ向け)
  画像URL (任意、作品カテゴリ向け)

タイムラインビュー (メイン画面)
  縦型タイムライン、年代順にカード表示
  年ごとにセクション分け
  カテゴリ別カラーアイコン
  カテゴリフィルター
  検索バー

ポートフォリオモード
  公開向けの閲覧ビュー
  「作品」「スキル」「資格」を中心にした表示
  プロフィール情報を上部に表示
  プレビューとHTMLエクスポートを分離

プロフィール設定
  名前
  肩書き / 自己紹介
  SNSリンク (Twitter, GitHub, Website等)

HTMLエクスポート
  ポートフォリオビューの内容を1枚のHTMLファイルとしてダウンロード
  CSS埋め込みでスタンドアロン動作
  レスポンシブ対応

テーマ
  ダークモード / ライトモード切り替え


============================================================
画面構成
============================================================

ヘッダー
  ロゴ + アプリ名
  ナビゲーション (年表 / ポートフォリオ / プロフィール)
  テーマ切替ボタン

年表画面 (メイン)
  カテゴリフィルタータブ
  検索バー
  タイムライン (カード時系列)
  右下にFABボタン (イベント追加)

ポートフォリオ画面
  プロフィール表示
  作品/スキル/資格イベントの表示
  HTMLエクスポートボタン

プロフィール画面
  名前 / 肩書き / 自己紹介の入力
  SNSリンク入力フィールド
  保存ボタン

イベント登録/編集モーダル
  タイトル / 年月 / カテゴリ (セレクト)
  説明 (テキストエリア)
  リンクURL / 画像URL
  保存 / キャンセル


============================================================
技術構成
============================================================

フレームワーク: なし (HTML / CSS / JavaScript)
